# KRB 獎牌變化預測工具

這是依玩家實測資料建立的 Kingdom Rush Battles 真人對戰獎牌變化預測工具。

公開網站：https://markma7373.github.io/krb-medal-calculator/

## 功能

- 輸入雙方卡片等級與比賽結果，直接預測獎牌變化。
- 輸入真實獎牌變化後，判斷是否命中或相差多少分數檔位。
- 可在瀏覽器本機記住我方牌組。
- 可一鍵複製完整測試資料；不會自動上傳任何資料。

## 現行模型

模型版本：2026-10-26-v6。雙方各取英雄、四塔、三法術中等級最高的三張卡，計算「我方總和 − 對方總和」，依下表預測獎牌變化。玩家等級、卡片稀有度與勝率不列入計算。

| 總和差額 | 獲勝 | 敗北 |
| --- | --- | --- |
| ≤ −9 | +50 | −9 |
| −8 | +50 | −10 |
| −7 | +48 | −12 |
| −6 | +46 | −14 |
| −5 | +44 | −16 |
| −4 | +41 | −19 |
| −3 | +39 | −21 |
| −2 | +36 | −24 |
| −1 | +33 | −27 |
| 0 | +30 | −30 |
| +1 | +28 | −32 |
| +2 | +25 | −35 |
| +3 | +22 | −38 |
| ≥ +4 | +20 | −40 |

獲勝 +50 上限目前依玩家提供的跡象暫採；敗北 −9 已確認。獲勝仍以 +20 為下限，敗北最多扣除 40 枚獎牌。
